## What it is

Verumap builds a deterministic map of a TypeScript codebase: its modules, layers, dependencies and how they compose. The map is derived from the source code itself, with no AI in the loop, so every finding traces back to the code that produced it.

## Why

AI coding agents and engineers new to a codebase spend their time rediscovering it file by file. Verumap gives both a complete, script-built map to read instead.

The same map is the foundation for reasoning about what tests should cover, and where the real coverage gaps are.

## Status

**Pre-release.** Verumap is a clean rebuild of [Codara](https://github.com/BilalMahmud12/codara), the prototype that proved the approach. TypeScript is the first supported language.
